# Extra Codes by Mam

These programs are additional reference implementations provided for extra practice and are separate from the official practical syllabus.

| File Name | Topic Covered |
|---|---|
| `Code01_ArrayListOperations.java` | `Collections.sort()`, `min()`, `max()` on `ArrayList` |
| `Code02_LinkedListOperations.java` | FIFO Queue operations (`offer`, `peek`, `poll`) |
| `Code03_CustomExceptionDemo.java` | Custom user-defined exception extending `Exception` |
| `Code04_ThreadPriorityDemo.java` | Thread priority management (`MIN_PRIORITY`, `MAX_PRIORITY`) |

---

## Program Details

### 1. Code01_ArrayListOperations.java
- **Aim:** Demonstrate sorting and finding minimum and maximum values in an `ArrayList`.
- **Concept:** `java.util.Collections` utility methods.
- **Compilation:** `javac Code01_ArrayListOperations.java`
- **Execution:** `java Code01_ArrayListOperations`

### 2. Code02_LinkedListOperations.java
- **Aim:** Demonstrate FIFO Queue operations using `LinkedList`.
- **Concept:** Queue interface methods implemented by `LinkedList` (`offer`, `peek`, `poll`).
- **Compilation:** `javac Code02_LinkedListOperations.java`
- **Execution:** `java Code02_LinkedListOperations`

### 3. Code03_CustomExceptionDemo.java
- **Aim:** Create and throw a user-defined checked exception.
- **Concept:** Custom exception class extending `java.lang.Exception`.
- **Compilation:** `javac Code03_CustomExceptionDemo.java`
- **Execution:** `java Code03_CustomExceptionDemo`

### 4. Code04_ThreadPriorityDemo.java
- **Aim:** Demonstrate setting and getting thread priorities.
- **Concept:** `Thread.MIN_PRIORITY` (1), `NORM_PRIORITY` (5), `MAX_PRIORITY` (10).
- **Compilation:** `javac Code04_ThreadPriorityDemo.java`
- **Execution:** `java Code04_ThreadPriorityDemo`
